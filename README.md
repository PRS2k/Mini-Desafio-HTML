Olá! Meu nome é **Daniel Pires**. Sou estudante do curso de **Desenvolvimento de Sistemas no SENAI**.

Atualmente, tenho domínio da estrutura e estilização de páginas (**HTML5 & CSS3**) e estou aprofundando meus conhecimentos em **JavaScript** para o desenvolvimento de aplicações completas e dinâmicas.

### 🛠️ Minhas Habilidades:
